    Thông tin kỹ thuật (mã băm SHA-256)

      Dấu thời gian Bitcoin (OpenTimestamps)

      Trình duyệt của bạn tự đóng dấu mã băm của từng file lên Bitcoin, không qua Tòa. Máy chủ đóng dấu không thấy file. Bitcoin xác nhận sau vài giờ; hãy tải file .ots về và giữ cùng file gốc.

        Tự kiểm tra biên nhận

        Tải biên nhận về máy và giữ cùng file gốc. Bất cứ lúc nào, bạn hoặc người khác (luật sư, Tòa) cũng tự kiểm tra được mà không cần tài khoản: file còn nguyên vẹn, biên nhận đúng chữ ký hệ thống và đã ghi lên chuỗi công khai.

        Kiểm tra biên nhận

        Lưu ý

        Hãy giữ nguyên file gốc. Nếu file bị gửi qua Zalo, nén, hoặc mở ra rồi lưu lại, Tòa sẽ thấy kết quả "Khác bản lưu chứng". Biên nhận chỉ chứng minh file đã có từ thời điểm trên, không chứng minh nội dung là thật.
